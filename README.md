# Paradise Island - Travel Brochure

## Project Description

A responsive travel brochure website for a fictional tropical destination called Paradise Island.

Created for Project 1.

## Features

- Responsive navigation bar
- Destination information and beach image
- Travel packages and pricing table
- Travel inquiry form
- Responsive desktop, tablet, and mobile layouts
- CSS Grid and Flexbox
- CSS variables and hover effects

## Technologies Used

- HTML5
- CSS3
